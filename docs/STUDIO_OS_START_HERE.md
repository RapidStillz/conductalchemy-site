# Studio OS — Start Here

Status: ACTIVE GOVERNANCE ENTRY POINT
Owner: RapidStillz / Conduct Alchemy

## Mandatory startup protocol

Before any person, agent, new conversation or automation proposes or produces work for Conduct Alchemy, RapidStillz or Studio OS, it must:

1. Load the current Constitution and governance rules.
2. Load the relevant project current-state file and active backlog.
3. Retrieve the canonical brand, design and creative assets from the approved DAM/source location.
4. Identify inherited decisions and assets before creating anything new.
5. Do not reopen or replace approved decisions without an explicit change request.
6. Continue the highest-priority unblocked production task.
7. Record new decisions, evidence, assets and status changes back into the organisational record.
8. Run a drift check before presenting, publishing or committing work.

## Non-negotiable operating rules

- Conduct Alchemy is creative-first; it is not licensing-first.
- RapidStillz Studio OS exists to enable governed, evidence-led and increasingly autonomous production.
- Approved canon is inherited, not recreated.
- Research from Food for Thought must be assessed and recorded as rejected, parked, tested, adopted or superseded before it changes production.
- Work should continue in coherent batches until a genuine approval, access, asset or consequential decision blocks progress.
- When one task is blocked, move to the next unblocked task in the active backlog.
- No visual work may be released without the actual approved logo, motif, typography and colour references loaded and checked.

## Current repository baseline

This repository currently contains a React + Vite application with routes for the homepage, licensing and admin. The homepage is presently only a placeholder and must not be treated as an approved design.

The following must be located and linked here before branded visual production resumes:

- Studio OS Constitution
- Governance plan
- Conduct Alchemy brand guidelines
- Master logo files
- Approved motif
- Approved fonts / typography specification
- Approved colour palette and tokens
- Tone of voice and positioning
- DAM / canonical asset location
- Conduct Alchemy product dossier
- Active production backlog
- Decision and evidence registers

## Drift gate

Before release, confirm:

- Canonical assets were loaded.
- No approved decision was silently reopened.
- No existing asset was unnecessarily recreated.
- Positioning remains creative-first.
- New tools or dependencies were approved.
- Evidence and status were recorded.

If any answer is no, the artefact is not release-ready.
